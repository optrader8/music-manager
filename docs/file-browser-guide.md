# File Browser 사용 가이드

Music Manager의 파일 브라우저 기능을 사용하여 음악 파일을 탐색하고 관리하는 방법을 설명합니다.

## 개요

파일 브라우저는 `/mnt/nas-music`에 마운트된 음악 라이브러리의 파일들을 웹 인터페이스를 통해 직접 관리할 수 있게 해주는 기능입니다.

## 접근 방법

1. 웹 브라우저에서 Music Manager에 로그인
2. 사이드바에서 **"Files"** 메뉴 클릭
3. 또는 직접 URL 접근: `http://localhost:32001/files`

## 주요 기능

### 1. 디렉토리 탐색

#### 기본 탐색
- **폴더 클릭**: 폴더를 클릭하여 하위 디렉토리로 이동
- **Breadcrumb 네비게이션**: 상단의 경로 표시줄을 통해 상위 폴더로 빠른 이동
- **그리드 뷰**: 파일과 폴더가 카드 형태로 표시

#### 파일 정보 표시
각 파일/폴더 카드에는 다음 정보가 표시됩니다:
- **아이콘**: 파일 타입에 따른 아이콘 (음악, 이미지, 텍스트, 폴더)
- **이름**: 파일/폴더명
- **크기**: 파일 크기 (폴더는 표시 안됨)
- **수정일**: 마지막 수정 날짜
- **권한**: 파일 권한 정보

### 2. 검색 기능

#### 실시간 검색
- 페이지 상단의 검색창에 키워드 입력
- 입력과 동시에 현재 디렉토리에서 파일명을 기준으로 필터링
- 검색어를 지우면 전체 목록이 다시 표시

#### 검색 팁
- 대소문자 구분하지 않음
- 파일명의 일부만 입력해도 검색 가능
- 확장자로도 검색 가능 (예: ".mp3", ".flac")

### 3. 파일 작업

각 파일/폴더 카드의 우측 상단에 있는 **⋮** (점 3개) 버튼을 클릭하면 작업 메뉴가 나타납니다.

#### 삭제 기능
1. **⋮** 버튼 클릭 → **"Delete"** 선택
2. 확인 대화상자에서 삭제 확인
3. **주의**: 폴더 삭제 시 하위 모든 내용이 함께 삭제됩니다
4. 삭제는 되돌릴 수 없으므로 신중하게 진행

#### 이름 변경
1. **⋮** 버튼 클릭 → **"Rename"** 선택
2. 새 이름 입력 대화상자에서 원하는 이름 입력
3. **확인** 클릭하여 변경 완료
4. 동일한 이름의 파일이 있으면 오류 메시지 표시

### 4. MP3 태그 편집

MP3 파일에 대해서는 추가적인 메타데이터 편집 기능을 제공합니다.

#### 태그 편집 시작
1. MP3 파일의 **⋮** 버튼 클릭 → **"Edit Tags"** 선택
2. MP3 태그 편집 모달 창이 열림
3. 현재 태그 정보가 자동으로 로드됨

#### 편집 가능한 태그
- **Title** (제목): 곡의 제목
- **Artist** (아티스트): 연주자/가수명
- **Album** (앨범): 앨범명
- **Genre** (장르): 음악 장르
- **Year** (연도): 발매 연도
- **Track Number** (트랙 번호): 앨범 내 트랙 순서

#### 태그 저장
1. 원하는 정보 입력/수정
2. **Save** 버튼 클릭
3. 성공 메시지 확인 후 모달 창 자동 닫힘

## 사용자 인터페이스 구성요소

### 상단 영역
- **페이지 제목**: "File Browser"
- **검색창**: 실시간 파일 검색

### Breadcrumb 네비게이션
```
Home > Albums > Artist Name > Album Name
```
- 각 경로 요소를 클릭하여 해당 디렉토리로 이동
- 루트 디렉토리는 "Home"으로 표시

### 파일 그리드
- 반응형 그리드 레이아웃 (화면 크기에 따라 컬럼 수 조정)
- 데스크톱: 최대 4열
- 태블릿: 최대 3열
- 모바일: 최대 2열

### 로딩 상태
- 초기 로딩 시 스켈레톤 UI 표시
- 파일 작업 중 로딩 인디케이터 표시

### 오류 처리
- 네트워크 오류 시 오류 메시지 표시
- 권한 없음, 파일 없음 등의 상황별 적절한 메시지 제공

## 토스트 알림

모든 파일 작업은 성공/실패 여부를 토스트 메시지로 알려줍니다:

### 성공 메시지
- "File deleted successfully" (파일 삭제 성공)
- "File renamed successfully" (이름 변경 성공)
- "MP3 tags updated successfully" (태그 수정 성공)

### 오류 메시지
- "Failed to delete file: [오류 내용]"
- "Failed to rename file: [오류 내용]"
- "Failed to update MP3 tags: [오류 내용]"

## 보안 및 제한사항

### 접근 제한
- 관리자 권한이 있는 사용자만 파일 브라우저 사용 가능
- `/mnt/nas-music` 디렉토리 외부 접근 불가
- 상대 경로를 통한 시스템 디렉토리 접근 차단

### 파일 작업 제한
- 시스템 파일 및 숨김 파일 접근 제한
- 안전하지 않은 파일명 사용 불가
- 심볼릭 링크를 통한 외부 경로 접근 차단

### 지원 파일 형식
- **음악 파일**: .mp3, .flac, .wav, .m4a
- **이미지 파일**: .jpg, .jpeg, .png, .gif
- **텍스트 파일**: .txt, .md
- **기타**: 모든 파일 유형 (단, MP3 태그 편집은 .mp3만 지원)

## 문제 해결

### 자주 발생하는 문제

#### 1. "Permission denied" 오류
**원인**: 파일/폴더에 대한 접근 권한이 없음
**해결방법**:
- 시스템 관리자에게 권한 확인 요청
- 파일 권한 설정 확인

#### 2. "Directory not found" 오류
**원인**: 요청한 디렉토리가 존재하지 않음
**해결방법**:
- 경로가 올바른지 확인
- 상위 디렉토리부터 다시 탐색

#### 3. MP3 태그 편집 실패
**원인**: 파일이 손상되었거나 읽기 전용
**해결방법**:
- 파일 권한 확인
- 다른 MP3 편집 도구로 파일 상태 확인

#### 4. 파일 업로드가 안됨
**참고**: 현재 버전에서는 파일 업로드 기능을 지원하지 않습니다. SSHFS나 다른 방법으로 파일을 서버에 복사한 후 파일 브라우저에서 관리하세요.

### 성능 최적화 팁

#### 대용량 디렉토리 탐색
- 검색 기능을 활용하여 원하는 파일을 빠르게 찾기
- 하위 디렉토리로 세분화하여 탐색

#### 빠른 네비게이션
- Breadcrumb을 활용한 상위 디렉토리 이동
